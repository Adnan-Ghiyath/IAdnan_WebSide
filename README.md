## About This Site

Built to bring together my desktop and web projects in one place, with live previews and source code links for each, plus a downloadable CV.

## Sections

- **Hero** — name, role, and core tech stack at a glance
- **Featured Projects** — my most impactful builds, each with a live preview, tech badges, and a source code link
- **More Projects** — smaller/earlier projects for anyone who wants to see the full range
- **Contact** — WhatsApp, Telegram, LinkedIn, GitHub, and email, all one click away
